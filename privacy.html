Privacy policy

This utility uses YouTube API Services. See the Google Privacy Policy.

Information and purpose

With the channel owner's permission, the utility accesses channel identity, video identifiers, titles, publication status and schedules, aggregate views, watch time and audience retention. OAuth credentials are used only for authorized API access. The data supports channel operations and performance review. It is not sold, used for advertising or used to train generalized AI models.

Storage and access

The current pilot stores credentials and API results on the owner's computer with restricted file permissions. Public website files and source repositories must not contain credentials or private API results. Any future cloud storage or processing must be reviewed and disclosed before deployment.

Revocation and deletion

The owner can revoke access in Google account permissions and request deletion using the contact below. The operator must stop unauthorized access, delete affected stored data within applicable YouTube API policy deadlines and periodically verify continued authorization for retained data. These procedures must be implemented before unattended deployment.
